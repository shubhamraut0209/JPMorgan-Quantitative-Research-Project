# JPMorgan Chase & Co. - Quantitative Research Project 💼📊

This repository contains the completed tasks for the **JPMorgan Chase Quantitative Research Virtual Job Simulation** hosted on Forage. The simulation mirrors the responsibilities of a Quantitative Researcher working with a commodity trading desk and a retail credit risk team.

## 📁 Contents

- `JPMC_Quantitative_Research_Colab.ipynb`: The Google Colab notebook with code implementations for all four tasks.
- `natural_gas_price_data.csv`: Monthly historical price data used for extrapolation and contract pricing.

## ✅ Tasks Performed

### 🧮 Task 1: Investigate and Analyze Price Data
- Cleaned and visualized monthly natural gas price data.
- Identified seasonal trends.
- Built a function to estimate gas prices for any past or future date using extrapolation.

### 📈 Task 2: Price a Commodity Storage Contract
- Developed a pricing model for a natural gas storage contract.
- Factored in injection/withdrawal rates, volume limits, fees, and storage costs.
- Simulated potential profits or losses based on pricing dynamics.

### 🔍 Task 3: Credit Risk Analysis
- Analyzed a loan dataset to estimate customer default probabilities.
- Transformed FICO scores into categorical bins using dynamic programming.
- Built and evaluated a predictive classification model.

### 📊 Task 4: Model Performance and Optimization
- Tuned the predictive model.
- Assessed classification performance using accuracy, precision, recall, and ROC-AUC.
- Interpreted the output for business decision-making.
